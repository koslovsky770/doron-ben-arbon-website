# וורדפרס — פרויקטים (סוג פוסט)

עותק של הקוד שרץ באתר החי (`wp-content/novamira-sandbox/doron-projects.php`).

## איך מוסיפים פרויקט

לוח הבקרה ← **פרויקטים** ← **הוספת פרויקט**:

| שדה | איפה מופיע |
|---|---|
| כותרת | כותרת הכרטיס |
| תיאור קצר | הטקסט בכרטיס |
| תמונת הפרויקט (תמונה ראשית) | תמונת הכרטיס בדף הבית (ובעמוד הקטגוריה אם אין תמונה נפרדת) |
| סוגי פרויקטים (תיווך מסחרי / שיווק פרויקטים / מגרשים) | קובע באיזה טאב ובאיזה עמוד פנימי הפרויקט יופיע |
| פרטי הפרויקט: מיקום, תגית 1, תגית 2 | שורת המיקום ושתי התגיות בכרטיס בדף הבית |
| תמונה לעמוד הקטגוריה (לא חובה) | תמונה אחרת לעמוד הפנימי |
| מאפיינים ← סדר | סדר ההצגה (מספר קטן = ראשון) |

הפרויקט מופיע אוטומטית:
- בדף הבית, בטאב **הכל** ובטאב של הקטגוריה שלו
- בעמוד הפנימי של הקטגוריה, בסקשן "עסקאות לדוגמה"

## עריכת העיצוב באלמנטור

תבניות ← **Loop Items** (תבניות לולאה):
- **כרטיס פרויקט - דף הבית** (153): הכרטיס בקרוסלות של דף הבית
- **שורת פרויקט - עמודי קטגוריה** (156): השורה בעמודים הפנימיים

שינוי בתבנית חל על כל הפרויקטים בבת אחת.

בדף הבית, הטאבים הם ווידג'ט Loop Carousel שמסונן לפי "סוג פרויקט".
בעמודים הפנימיים זה ווידג'ט Loop Grid.
