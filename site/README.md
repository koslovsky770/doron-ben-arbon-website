# דורון בן ארבון — דף הבית (שלב 1)

דף בית + תפריט, לפי מסמך האיפיון, בעיצוב תבנית ה־Figma
*Free Real Estate Portfolio website template* — RTL מלא, מוכן לדחיפה ל־Lovable.

## מבנה

```
site/
├─ preview/index.html        ← תצוגה מקדימה עצמאית (לפתיחה בדפדפן)
└─ lovable/                  ← מה שנדחף ל-Lovable
   ├─ tailwind.config.ts
   ├─ public/
   │  ├─ images/*.jpg        ← 12 תמונות שנוצרו
   │  └─ fonts/Polin-*.woff2 ← פונט המותג
   └─ src/
      ├─ index.css           ← @font-face + טוקני עיצוב (HSL CSS variables)
      ├─ data/site.ts        ← כל התוכן במקום אחד
      ├─ pages/Index.tsx
      └─ components/site/    ← Navbar, Hero, About, FeaturedProjects, Services,
                                GoogleReviews, Testimonials, CtaBanner, Footer,
                                Logo, Icons
```

שני הקבצים זהים ויזואלית. ה־HTML הוא לתצוגה בלבד ואינו נדחף.

## טיפוגרפיה

**Polin** — פונט המותג, בשני חתכים בלבד (Regular + Bold). ב־`index.css` מוגדרים
טווחי משקל כדי שכל `font-weight` של Tailwind ימופה לקובץ אמיתי:

| טווח | קובץ |
|---|---|
| `100–500` (normal / medium) | `Polin-Regular.woff2` |
| `600–900` (semibold → black) | `Polin-Bold.woff2` |

בלי זה הדפדפן היה מייצר bold מזויף. `Assistant` נשאר בסטאק רק כגיבוי לתו חסר.

סקאלה: `text-d1` = 92px, `text-d2` = 59px, `text-d3` = 24px — עם `clamp()`.

### ביקורות חיות (שלב הבא)

הקרוסלה קוראת מהמערך `googleReviews`. אי אפשר למשוך ביקורות מגוגל ישירות
מהדפדפן — אין endpoint ציבורי, CORS חוסם, וגרידה נוגדת את תנאי השימוש.
הדרך הנתמכת היא **Google Places API** דרך שרת:

1. ב־Lovable: להפעיל Supabase ולהוסיף edge function `google-reviews`.
2. לשמור `GOOGLE_MAPS_API_KEY` כסוד (לא בקוד הלקוח).
3. ה־function קוראת ל־Place Details ומחזירה את `result.reviews`.
4. להחליף ב־`GoogleReviews.tsx` את הקריאה למערך הסטטי ב־`useQuery` לפונקציה,
   עם המערך הנוכחי כ־fallback.

מגבלה של גוגל: Place Details מחזיר **עד 5 ביקורות**, לא את כל ה־23.
כדי להציג את כולן צריך שירות צד־שלישי (Elfsight / Trustindex / EmbedSocial).

את ה־`place_id` בפורמט `ChIJ…` צריך לשלוף פעם אחת דרך Find Place; מה שידוע
כרגע שמור ב־`googleBusiness`: `cid` ו־`fid`.

## עמוד המלצות

`src/pages/Testimonials.tsx` — כותרת ("ממליצים עלינו") ← `<Testimonials
items={...}/>` עם **כל 9** ההמלצות העסקיות פתוחות ברשת אחת (בלי גלילה/קיצור —
3 מהפרוספקט הרשמי + 6 מהאתר הישן) ← `<GoogleReviews/>` (הסליידר הקיים) ← CTA
← Footer. קומפוננטת `Testimonials` קיבלה פרופ `items` אופציונלי (ברירת מחדל:
שלוש ההמלצות שכבר מוצגות בדף הבית) כדי שדף הבית והעמוד המלא ישתמשו באותה
קומפוננטה בלי כפילות קוד. שש ההמלצות הנוספות (`additionalTestimonials`
ב-`site.ts`) מגיעות מהאתר הישן — הועתקו כלשונן, תוקנו רק רווחים/פיסוק
(המלצה אחת, של אסתי ברכר, הייתה חלקית/לא ברורה גם במקור ונשארה כך בכוונה,
בלי להשלים מילים).

## עמוד תיווך מסחרי

נבנה לפי תבנית ה-Figma (סקשן "Service") ומסמך האיפיון (סעיף "עמוד: תיווך מסחרי"),
בעיצוב וטוקנים זהים לדף הבית ולעמוד האודות:

```
src/pages/Commercial.tsx
└─ Navbar (current="/commercial") → CommercialHero → CommercialListings → CtaBanner → Footer
```

- **מיפוי מתבנית ה-Figma** — עמוד ה-"Service" המקורי (חברת בנייה, "Pinnacle") כלל
  Hero + סקשן "Wrapper" (כותרת גדולה וכפתור בצד אחד, פסקת פתיחה ובלוקים חוזרים
  של כותרת+טקסט+תמונה בצד השני) + טופס יצירת קשר. הטופס הושמט — "בלי טופס
  יצירת קשר" זה כלל קבוע באתר (ראו הטבלה למעלה) — והוחלף ב-`CtaBanner` הקיים.
- **`CommercialHero`** — מבנה זהה ל-`AboutHero` (גרדיאנט, קונטיינר, כותרת H3 +
  פסקה בשורה אחת), עם תמונה גדולה אחת (`svc-commercial.jpg`) במקום שתי תמונות.
- **`CommercialListings`** — משחזר את "Wrapper" של פיגמה: עמודת כותרת (`d2`)
  וכפתור CTA בצד אחד, ופסקת הסבר + הפרויקטים הקיימים מקטגוריית `commercial`
  (חדד, גלורי, משכן התכלת) כבלוקים חוזרים של כותרת (`h6`) + תיאור + תמונה —
  בדיוק לפי מסמך האיפיון ("לכל פריט: תמונה + כותרת + תיאור קצר"), בלי מיקום
  או תגיות (אלה מוצגות בכרטיסי `FeaturedProjects` בדף הבית).
- **אין תוכן חדש** — כל שלושת הפרויקטים כבר היו קיימים ב-`site.ts`; נוספו רק
  כותרות ופסקאות ההסבר של העמוד עצמו (`commercialPage`).
- **תצוגה מקדימה** — `site/preview/commercial.html`, זהה ויזואלית ל-React,
  ולינקי "תיווך מסחרי" ב-`index.html` ו-`about.html` (תפריט, פוטר וכרטיס
  השירות) עודכנו להצביע אליו במקום לעוגן `#services`.
